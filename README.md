# InventSea demo

Άνοιξε το `index.html` σε browser για δοκιμή στον υπολογιστή. Για δοκιμή σε κινητό, σύνδεσε υπολογιστή και κινητό στο ίδιο έμπιστο Wi-Fi και εκτέλεσε μέσα στον φάκελο `demo`:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Στο κινητό άνοιξε `http://<τοπική-IP-υπολογιστή>:8000`. Σταμάτησε τον server με Ctrl+C μετά τη δοκιμή.

## Σενάριο

1. Αναζήτησε rice και καταχώρισε `12,5` kg.
2. Άνοιξε δεύτερο είδος, βάλε `0` και πρόσθεσε σημείωση.
3. Άφησε ένα είδος αμέτρητο και άνοιξε τον έλεγχο. Σύγκρινε τις δύο καταστάσεις.
4. Άνοιξε την προεπισκόπηση και εκτύπωσε ή αποθήκευσε σε PDF από τον browser.
5. Χρησιμοποίησε την «Reset demo» για επόμενη δοκιμή.

Οι καταχωρίσεις αποθηκεύονται στον τρέχοντα browser όπου επιτρέπεται η τοπική αποθήκευση. Το demo χρησιμοποιεί συνθετικά δεδομένα. Η δοκιμή της λειτουργίας χωρίς σύνδεση σε πλοίο και η σύνδεση με ERP ανήκουν σε επόμενα στάδια.
